Accessibility

Accessibility statement

The site aims to be usable with a keyboard, zoom, small screens and assistive technology. It has not yet received an independent accessibility audit.

Measures included

Semantic headings, labelled form controls, a skip link, visible keyboard focus, responsive layouts, text alternatives for functional graphics and core content rendered directly in HTML.

JavaScript

Interactive route and escalation tools require JavaScript. The same pages retain static reporting links and escalation guidance when JavaScript is unavailable.

Known limitations

The site has not yet been tested with every browser and assistive-technology combination. Some external public-body websites may have their own accessibility limitations.

Report an accessibility problem

Use the factual correction form and state the page, device or assistive technology, the problem encountered and the task you were trying to complete. Do not include sensitive personal information.

Open contact and corrections

Review status

Initial internal structural review completed 5 August 2026. Target standard: WCAG 2.2 AA, without claiming full conformance before broader testing.
