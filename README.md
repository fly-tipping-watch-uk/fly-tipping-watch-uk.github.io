# Fly-Tipping Watch UK — review-fixed launch build

Version 2.0 makes the site suitable for a careful public information soft launch.

## Main changes

- Core statistics, public-body records, source entries and the case study are present directly in HTML.
- JavaScript enhances the pages but is not the only source of substantive content.
- The unfinished public submission setup has been removed from navigation.
- About, contact/corrections, privacy and accessibility pages are included.
- GitHub issue templates provide a free public route for factual corrections and broken links.
- The Scotland £53 million wording now states that it covers litter and fly-tipping clean-up combined.
- Canonical addresses, social metadata, a favicon and a social-sharing card are included.

## Important limitation

The site is not yet collecting private case submissions, contributor contact details or evidence. Do not activate submissions until a private contact route, moderation workflow, retention policy and contributor privacy notice are ready.
